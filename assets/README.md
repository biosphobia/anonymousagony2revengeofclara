# assets/

Drop the opening-credits song here as:

    assets/down-with-the-sickness.mp3

("Down With the Sickness" by Disturbed — supplied by you; not included in
this repo for copyright reasons.)

The opening credits are synced to this file's own playback clock, so the
timing matches whatever you upload. To end the credits exactly at the end
of the first chorus, set `CREDITS_END_SEC` (seconds) near the top of
`js/game.js` to that timestamp in your file.
